# Unraid templates: SysMonitor

| App | Description | Source |
|---|---|---|
| SysMonitor | Syslog server, status monitor and local-AI digests for Home Assistant | https://github.com/netadmindave/sysmonitor |

Install from the Unraid **Apps** tab, or copy `templates/sysmonitor.xml` to
`/boot/config/plugins/dockerMan/templates-user/` and use Docker → Add Container.

Template problems: open an issue here. App problems: open an issue on the app's repository.
